# Plume Libre — Next.js + Supabase

## Installation
1. Installer Node.js 20+.
2. `npm install`
3. Copier `.env.example` vers `.env.local`.
4. Renseigner `NEXT_PUBLIC_SUPABASE_URL` et `NEXT_PUBLIC_SUPABASE_ANON_KEY`.
5. `npm run dev`

Pages incluses :
- `/`
- `/decouvrir`
- `/connexion`
- `/publier`
- `/dashboard`
- `/oeuvre/[id]`
- `/lecture/[id]`

Le projet est un socle connecté à ta base actuelle. Les boutons de notation, favoris, corrections et suggestions constituent la prochaine étape fonctionnelle. Ne mets jamais la clé `service_role` dans le navigateur.
